2D 게임 프로토타입을 만들어줘.

목표:

* 그래픽, 연출, UI 없이도 재미 검증 가능한 최소 프로토타입.
* 핵심은 "Modifier 조합으로 공격 행동이 예상 못한 방식으로 변화하는지" 테스트하는 것.

## 기본 구조

### Player

* 이동 가능 (WASD 또는 방향키)
* 자동 또는 버튼 공격 (둘 중 하나 아무거나)
* 기본 공격은 직선 투사체 1개 발사

### Enemy

* 단순 AI
* 플레이어 방향으로 이동
* 투사체 맞으면 죽음
* 복잡한 행동 없음

---

## Modifier 시스템 (핵심)

Modifier는 동시에 여러 개 적용 가능해야 한다.
Modifier는 ON/OFF 형태로 쉽게 바꿀 수 있어야 한다.

### Modifier 1: Bounce

* 투사체가 적을 맞으면 사라지지 않고
* 근처 다른 적에게 튕김

### Modifier 2: Split

* 투사체가 적을 맞으면 2개로 분열
* 각기 다른 방향으로 이동

### Modifier 3: Mark

* 투사체가 적을 맞으면 표식(Mark) 부여
* Mark된 적을 다시 맞으면 추가 반응 발생
* 추가 반응은 간단한 폭발 또는 추가 투사체 생성

---

## 중요한 설계 규칙 (반드시 지킬 것)

* 데미지 증가, 공격속도 증가 같은 단순 수치 업그레이드 금지
* 재미는 행동 변화에서만 나오게 설계
* Modifier 각각은 단독으로는 평범하지만,
  여러 개 조합 시 예상 못한 상호작용이 발생해야 함
